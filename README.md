# zelrijdende-auto
Een schoolproject waarin we een zelfrijdende auto simuleren en ontwikkelen.
#  Project Zelfrijdende Auto

## Over het project
Voor dit project werken we aan het ontwerpen en ontwikkelen van een zelfrijdende auto. Het doel is om te onderzoeken hoe een auto zelfstandig zijn omgeving kan herkennen en daarop kan reageren.

We werken hierbij samen in een team en gebruiken GitHub om onze bestanden, code en voortgang bij te houden.

## Doelstellingen
- Onderzoeken hoe een zelfrijdende auto werkt.
- Een simulatie van een zelfrijdende auto ontwikkelen.
- Sensoren en verkeerssituaties leren begrijpen.
- Samenwerken met behulp van GitHub en Scrum.

## Gebruikte technologieën
- Python
- GitHub
- Simulatiesoftware
- Sensoren (indien van toepassing)

## Samenwerking
We werken volgens de Scrum-methode. Via ons Kanban-bord verdelen we de taken en volgen we de voortgang.

## Team
Dit project wordt gemaakt als schoolopdracht.

## Status
 Project in ontwikkeling.

**Opmerking:** Dit project is bedoeld als educatief simulatieproject en niet als een auto die zelfstandig op openbare wegen rijdt.
